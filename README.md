# VentiLearn

แพลตฟอร์มการเรียนรู้การพยาบาลผู้ป่วยที่ใช้เครื่องช่วยหายใจ (Ventilator Nursing Learning Application)

## รายละเอียดโปรเจค
VentiLearn เป็นเว็บแอปพลิเคชันสำหรับการเรียนรู้เกี่ยวกับการดูแลผู้ป่วยที่ใช้เครื่องช่วยหายใจ ถูกออกแบบมาเพื่อนิสิตพยาบาลและบุคลากรทางการแพทย์ โดยมีเป้าหมายเพื่อเสริมสร้างความเข้าใจในการทำงานของเครื่องช่วยหายใจและการจัดการดูแลผู้ป่วยอย่างปลอดภัย

### คุณสมบัติหลัก
- **การเรียนรู้แบบโต้ตอบ:** เรียนรู้การตั้งค่าและส่วนประกอบของเครื่องช่วยหายใจ
- **รองรับการเข้าถึง (Accessibility):** มีฟังก์ชันปรับขนาดตัวอักษรเพื่อให้อ่านง่ายสำหรับทุกคน
- **โหมดการแสดงผล (Themes):** รองรับทั้ง Light mode และ Dark mode
- **การออกแบบที่ตอบสนอง (Responsive Design):** สามารถใช้งานได้ในหลายขนาดหน้าจอ
- **ธีมเอกลักษณ์:** ใช้โทนสีม่วงซึ่งเป็นสีประจำมหาวิทยาลัยพะเยา

## การติดตั้งและการใช้งาน
โปรเจคนี้เป็น Single Page Application (SPA) ที่สร้างจาก HTML, CSS และ JavaScript 
คุณสามารถเริ่มต้นใช้งานได้ง่ายๆ โดยการดับเบิลคลิกเปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์ใดก็ได้ โดยไม่ต้องติดตั้งเซิร์ฟเวอร์เพิ่มเติม
